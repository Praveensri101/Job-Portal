# Open Source Job Portal – Detailed Project Description

**Project Name:** Open Source Job Portal  
**Technology Stack:** Python, Flask, SQLite, HTML, CSS

## Project Overview
The Open Source Job Portal is a web-based application developed using Python and Flask to connect job seekers with employment opportunities. It provides a platform where users can create accounts, explore available job openings, search for relevant positions, and submit job applications. The application also allows employers or registered users to post job vacancies and manage recruitment-related activities.

## Key Features
- **User Registration and Login:** Provides account creation and authentication functionality for users.
- **Job Listings:** Displays available job opportunities with relevant information.
- **Job Search:** Allows users to search for jobs based on keywords.
- **Job Posting:** Enables users to add new job vacancies through a dedicated form.
- **Job Details:** Displays detailed information about selected job openings.
- **Job Applications:** Allows job seekers to apply for available positions.
- **Application Tracking:** Provides a section where users can view their submitted applications.
- **Database Management:** Uses SQLite to store user information, job details, and application records.

## Implementation
The backend functionality is developed using Python and the Flask framework. SQLite is used for database operations, while HTML and CSS are used to build the user interface. Flask routes handle user authentication, job searching, job posting, and application processing.

## Project Objective
The main objective is to simplify the job-search process by providing a centralized platform for job seekers and employers to interact efficiently.
